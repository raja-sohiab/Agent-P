# Evidence Rules

Use evidence in this order:

1. Explicit input CSV information.
2. Usable information from the company's website.
3. Strong, defensible category-level understanding of the business and actual service.
4. Broader commercially logical reasoning only when still grounded.

Website access is helpful, not mandatory. A 403, 404, 429, timeout, challenge page, JavaScript-only page, irrelevant page, or inaccessible site is an evidence condition, not an automatic batch failure. Continue using stronger available evidence and do not pretend unavailable information was observed.

Never invent company-specific facts, customer intent, capabilities, results, or website observations. Prefer a broader accurate message over unsupported specificity. Fail only an individual row when the available information is genuinely insufficient for an evidence-grounded message; do not stop an otherwise processable batch.
